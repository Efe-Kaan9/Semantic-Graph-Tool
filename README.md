# Semantic Graph Tool

A Model Context Protocol (MCP) server that builds a queryable, semantic, and structural graph of any Python codebase. It exposes this graph to LLMs (like Claude, Cursor, etc.) to help them understand your codebase better without manually reading hundreds of files.

This project was built as a portfolio piece and is open-sourced for anyone who might find it useful.

## Features

- **Semantic Search**: Understands natural language queries to find relevant code (`search_codebase`).
- **Graph Exploration**: Traces call dependencies and blast radius (`explore_graph`).
- **Code Reading**: Extracts exact source lines for a specific node/function (`read_node_code`).
- **Graph Visualization**: Generates Mermaid.js diagrams of your call graph (`visualize_graph`).
- **Structural Insights**: Finds dead code (orphan methods), highly connected nodes, and circular dependencies (`get_structural_insights`).
- **JIT Sync**: Automatically detects file changes and updates the graph instantly before every query.

## Setup

1. **Create a virtual environment and install dependencies**:
   ```bash
   python -m venv venv
   # On Windows
   .\venv\Scripts\pip install -r requirements.txt
   # On Mac/Linux
   source venv/bin/activate
   pip install -r requirements.txt
   ```

2. **Configure your MCP Client**:
   Add the following to your MCP client configuration (e.g., `claude_desktop_config.json`):
   ```json
   {
     "mcpServers": {
       "semantic-graph": {
         "command": "/path/to/your/venv/bin/python",
         "args": [
           "/path/to/semantic-graph/server.py"
         ],
         "env": {},
         "description": "Semantic Code Knowledge Graph MCP Server."
       }
     }
   }
   ```
   *Make sure to update the absolute paths for the `command` and `args` to match where you cloned this repository.*
